## D. ข้อมูลภาษาไทย: คณิต/โค้ด/ความรู้/ข้อสอบ, instruction, แชตหลายเทิร์น, tool-use ไทย, การคิดเป็นภาษาไทย, สรุปข่าว, QA กฎหมาย/การแพทย์

- **ข้อสรุปตรงๆ:** tool-use ภาษาไทยที่ไม่ได้แปลมาและมีเฉลยให้ตรวจ ตอนนี้มีอยู่ชุดเดียวคือ **ThaiLLM/med-tool-use** ใช้สอนว่าเมื่อไรควรเรียก tool ไหน และเมื่อไรไม่ควรเรียก (no-tool 62%) แต่จำกัดอยู่ที่โดเมนการแพทย์ 7 tools เป็นการเลือก tool รอบเดียว ส่วนข้อมูลไทยแบบ agent หลายรอบ (terminal/ไฟล์/เว็บ) **ยังไม่มีบน HF** ต้องให้ครูสร้างจาก prompt ไทยเอง
- **ต้องแก้ข้อมูลรอบก่อน:** "Thai AutoIF 38,753" ใน typhoon-s **ไม่ได้เป็นภาษาไทยทั้งหมด** สุ่ม 1,200 แถว เจอ autoif 299 แถว ในนั้นมี prompt ภาษาไทยแค่ 117 แถว (≈39% คิดเป็นราว 15k แถว เป็นค่าประมาณจากตัวอย่าง) และ**ชุดนี้ไม่มีฟังก์ชันตรวจมาด้วย** constraint เขียนเป็นภาษาธรรมชาติใน system/user ต้องเขียนตัวตรวจเองหรือใช้ LLM-judge
- ข้อมูลที่มี "thinking เป็นภาษาไทย" มีแต่ชุดสังเคราะห์หรือแปล: thai-magpie-qwen3-think (Qwen3-32B, 52k), Thiraput01 (แปลจาก trace ของ Opus 4.6 ด้วย typhoon-translate-4b), tiny-aya th (NC), Thai-R1-Distill (รอบก่อน) และ**ไม่มีชุดไหนมีตัวตรวจคำตอบ** ยกเว้นส่วนคณิตที่มีเฉลย
- กฎหมาย/การแพทย์มีชุดที่**ผู้เชี่ยวชาญตรวจแล้ว**ไม่กี่ชุด (WangchanX-Legal train, land-tax QA, med-qas-golden) ที่เหลือเป็นข้อมูลสังเคราะห์ เสี่ยง hallucination ด้านการแพทย์และกฎหมาย และพบชุดข้อสอบ/benchmark ที่แปลเป็นไทยและห้ามเทรนอยู่หลายชุด (ดูท้ายตาราง) **ระวัง: O-NET M6 ที่มีอยู่แล้วเป็นส่วนหนึ่งของ ThaiExam-onet ดังนั้น ThaiExam-onet ใช้เป็น eval ที่สะอาดไม่ได้แล้ว**
