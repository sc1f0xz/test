## C. Agent ค้นเว็บ/วิจัยเชิงลึกที่ไม่อิง wiki: multi-hop บนเว็บจริง, อ้างอิง URL, ตรวจข้อเท็จจริง, trace deep-research และการตัดสินใจว่าจะค้นหรือไม่ค้น

- **ข้อมูลในหมวดนี้มี wiki ปนอยู่มาก และต้องแก้ข้อมูลจากรอบก่อน:** `artillerywu/DeepResearch-9K` paper (arXiv 2603.01152) ระบุว่า seed มาจาก HotpotQA / 2WikiMultihopQA / MuSiQue อย่างละ 1,000 ข้อ จึงเป็น **wiki 100% ต้องตัดออก** · `Alibaba-NLP/WebShaper` มี 399 จาก 500 แถว (80%) ที่อ้าง en.wikipedia (967 จาก 4,370 URL) · `Lk123/InfoSeek` สร้าง research tree จาก href ของหน้า Wikipedia · `PersonalAILab/AFM-WebAgent-SFT` เป็น wiki 48.6% (2wiki/popqa/musique 3,694 จาก 7,607 แถว)
- **การปนเปื้อน BrowseComp มี 2 ระดับ:** (1) **ปนตรง** คือชุด `rl-rag/browsecomp-*` (รวม `browsecomp-gptoss-clean-qwen35-sft`) ซึ่งเป็น trajectory ที่รันบน BrowseComp test เอง (1,266 ข้อ) และ `AFM-WebAgent-RL` ที่มี `browsercomp_zh` 266 แถว (คือ BrowseComp-ZH) → **ห้ามใช้** (2) **ปนแค่สไตล์** คือ `browsecomp_gpt5`/`browsecomp_32b` ใน DR Tulu (916 แถว) ซึ่ง paper บอกว่า "GPT-4.1 สร้างคำถามแนว BrowseComp 916 ข้อ" ไม่ได้คัดลอกมาจากชุดทดสอบ แต่ตัวอย่างที่เห็นเป็นคำถามแบบซ่อนชื่อ entity จากหน้า Wikipedia (ชุดพี่น้อง `rl-rag/bc_synthetic_*` มี explanation ชี้ไปที่ en.wikipedia ทั้งหมด) จึงควรตัดออกด้วยเหตุผลเรื่อง wiki · ผลวัดความซ้ำกับ BrowseComp test จริง (ถอดรหัสครบ 1,266 ข้อ แล้วเทียบกับ 916 ข้อ): **ซ้ำแบบตรงตัว 0 ข้อ** · token-Jaccard สูงสุด 0.226 · มีแค่ 11 ข้อที่เกิน 0.2 และ 0 ข้อที่เกิน 0.3 แปลว่า**ไม่ได้ปนเปื้อนตรง** แต่ยังควรตัดออกเพราะเป็น wiki
- **ระบบค้นที่ใช้ (backend):** DR Tulu ใช้ Serper (Google) + Crawl4AI/Jina สำหรับเปิดหน้าเว็บ + Semantic Scholar · OpenResearcher ใช้ **คลังออฟไลน์** FineWeb 15M เอกสาร + gold doc ประมาณ 10K (ได้มาจาก Serper) ค้นด้วย Qwen3-Embedding-8B · AFM/TaskCraft ใช้ web/pdf/image tool · Nemotron MCQA ใช้ search ที่ "return results from google" + browse · DeepResearchGym ใช้ ClueWeb22 (มีแต่ log ของ query) · router-labels ใช้ Exa
- **ชุดสำหรับสอนว่า "เมื่อไหร่ควรค้น" มีน้อยมาก:** ยังไม่มีชุด train ที่มี label คุณภาพดีให้ใช้ ทางที่ใช้ได้จริงคือ (ก) ใช้ `primary_intent` ของ SearchArena (Creative Generation 2,287 / Text Processing 752 / Explanation 2,505 ซึ่งมักไม่ต้องค้น เทียบกับ Factual Lookup 4,655 / Info Synthesis 4,477) ให้ครูตัดสินเองว่าจะค้นหรือไม่ (ข) ใช้ FreshQA-multilingual ที่**มีภาษาไทย** และ label `fact_type` (never/slow/fast-changing) เป็น eval
